Why We're Building This

This Slack agent turns Slack into the primary communication and data-collection tool for frontline nutrition workers in the Jagruti program.

Field workers in rural areas find complex mobile apps difficult — but they already use messaging apps daily. By making Slack the interface via native Agent Builder, we remove friction and boost data quality.

Daily PromptsField workers log observations consistently, building reliable longitudinal data.
Salesforce as TruthAll data stored directly in the existing Salesforce org — no sync problems.
Critical Case DetectionAutomatic identification of severely malnourished children for early intervention.
AI Clinical ReportsRaw notes → professional medical summaries via Claude + WHO criteria.
Real-Time Search (RTS)Agent always pulls the freshest workspace context before any action.
Slack Canvas ReportsBeautiful, formatted, permanent records inside native Slack surfaces.

Architecture

0Salesforce Setup (Most Critical Phase)

This phase establishes the data foundation everything else depends on. Three things must be verified:

  1. Activate MCP Server — enables the Salesforce MCP bridge so the Slack agent can query and write Salesforce data.
  2. Create External Client App — with the correct OAuth scopes for API access (at minimum: api, refresh_token, offline_access).
  3. Verify Custom Objects Exist — confirm Child__c, Experience_Log__c, and all referenced fields are present in the org.
Salesforce is the single source of truth. If this phase is incomplete, every subsequent phase will fail — RTS returns empty, critical detection finds nothing, and reports have no data.

Step 3.3 — Create Real-Time Search (RTS) Helper

Create file rts_helper.py:

# rts_helper.py - Real-Time Search (RTS) for Jagruti Agent
from datetime import datetime

def real_time_search(query: str = "nutrition OR SAM OR stunting OR feeding", limit: int = 15):
    """
    Pulls freshest context from Slack + Salesforce before any major action.
    """
    results = []

    # Slack MCP Server — search recent messages
    slack_results = slack_mcp.call(
        tool="search_messages",
        params={
            "query": query,
            "channels": ["field-worker-experiences", "critical-cases"],
            "time_range": "last_7_days",
            "limit": limit
        }
    )
    results.extend(slack_results)

    # Salesforce MCP — latest structured data
    salesforce_results = salesforce_mcp.call(
        tool="query",
        params={
            "soql": f"""
                SELECT Id, Narrative__c, Worker_Name__c, Date__c
                FROM Experience_Log__c
                WHERE Date__c = LAST_N_DAYS:7
                ORDER BY Date__c DESC LIMIT {limit}
            """
        }
    )
    results.extend(salesforce_results)

    results = sorted(results, key=lambda x: x.get('timestamp', ''), reverse=True)
    print(f"RTS completed at {datetime.now()}. Found {len(results)} recent items.")
    return results[:limit]


if __name__ == "__main__":
    fresh_context = real_time_search("SAM OR malnourished", limit=10)
    print("RTS Output:", fresh_context)

4Critical Case Detection & Alerts

Step 4.1 — Main Detection Script

Create critical_case_detector.py:

# critical_case_detector.py
from datetime import datetime
from rts_helper import real_time_search

def detect_critical_cases():
    print(f"Starting critical case detection at {datetime.now()}")

    # Step 1: RTS for unstructured signals
    fresh_context = real_time_search(
        query="SAM OR severely malnourished OR critical OR urgent",
        limit=20
    )

    # Step 2: Salesforce query for structured high-risk children
    high_risk = salesforce_mcp.call(
        tool="query",
        params={
            "soql": """
                SELECT Id, Name, SAM_Score__c, Stunted__c, Wasted__c,
                       Guardian_Name__c, Location__c
                FROM Child__c
                WHERE SAM_Score__c >= 2
                   OR Stunted__c = true
                   OR Wasted__c = true
                ORDER BY SAM_Score__c DESC
                LIMIT 10
            """
        }
    )

    if not high_risk:
        print("No critical cases found today.")
        return

    # Step 3: Clinical summary from Claude
    clinical_summary = claude.call(
        system_prompt="You are an experienced pediatric nutritionist...",
        user_message=f"Critical cases and observations: {fresh_context + high_risk}"
    )

    # Step 4: Rich alert via Slack MCP
    slack_mcp.call(
        tool="send_message",
        params={
            "channel": "critical-cases",
            "text": f"🚨 {len(high_risk)} Critical Cases - {datetime.now():%Y-%m-%d}",
            "blocks": [
                {"type": "header",
                 "text": {"type": "plain_text", "text": "Critical Nutrition Alert"}},
                {"type": "section",
                 "text": {"type": "mrkdwn", "text": clinical_summary}}
            ]
        }
    )

    # Step 5: Persistent Canvas report
    slack_mcp.call(
        tool="create_canvas",
        params={
            "title": f"Critical Cases Report - {datetime.now():%Y-%m-%d}",
            "content": clinical_summary,
            "channel": "critical-cases"
        }
    )
    print("Critical case alert posted successfully.")


if __name__ == "__main__":
    detect_critical_cases()

5AI Clinical Report Generation

Step 5.1 — Report Generator Script

Create clinical_report_generator.py:

# clinical_report_generator.py
from datetime import datetime
from rts_helper import real_time_search

def generate_clinical_report():
    print(f"Generating clinical report at {datetime.now()}")

    # Step 1: RTS (mandatory for freshness)
    context = real_time_search(
        query="child nutrition OR SAM OR feeding OR stunting OR wasting",
        limit=20
    )

    # Step 2: Claude with strict clinical prompt
    system_prompt = """
You are an experienced pediatric nutritionist working in rural India
with 15+ years experience.

Analyze the field worker observations. Structure your response EXACTLY:

1. **Executive Summary** (2-3 sentences)
2. **Key Themes Identified** (bullet points)
3. **Children Requiring Urgent Attention** (with WHO criteria)
4. **Recommended Counselling Topics** (with justification)
5. **Suggested Mother Education Content** (video ideas)
6. **Overall Program Recommendations**

Use WHO standards for SAM, Stunting, and Wasting.
Be compassionate but clinically precise.
"""

    report = claude.call(
        system_prompt=system_prompt,
        user_message=f"Latest observations:\n{context}"
    )

    # Step 3: Deliver via Slack MCP (rich message + Canvas)
    slack_mcp.call(
        tool="send_message",
        params={
            "channel": "reports",
            "text": "📊 Clinical Report Generated",
            "blocks": [
                {"type": "header",
                 "text": {"type": "plain_text", "text": "Jagruti Clinical Summary"}},
                {"type": "section",
                 "text": {"type": "mrkdwn", "text": report}}
            ]
        }
    )

    canvas = slack_mcp.call(
        tool="create_canvas",
        params={
            "title": f"Jagruti Clinical Report - {datetime.now():%Y-%m-%d}",
            "content": report,
            "channel": "reports"
        }
    )

    print(f"Report posted. Canvas URL: {canvas.get('url', 'N/A')}")
    return report


if __name__ == "__main__":
    generate_clinical_report()
