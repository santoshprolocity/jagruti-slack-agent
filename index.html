Project Overview

This Slack agent turns Slack into the main communication and data collection tool for frontline nutrition workers in the Jagruti program.

WHY: Field workers in rural areas often find complex mobile apps difficult. They already use messaging apps daily. By making Slack the primary interface and using Slack's native Agent Builder, we remove friction and create a native Slack experience.

Key Features

  • 01 Daily prompts for field workers to log experiences. Consistent daily input creates reliable longitudinal data about children.
  • 02 All data stored directly in Salesforce (no custom database). Jagruti already has a Salesforce org. Duplicating data creates sync problems.
  • 03 Automatic detection of critically malnourished children. Early detection can save lives.
  • 04 AI-powered clinical reports with Real-Time Search (RTS). Raw notes are turned into professional medical summaries using the freshest data.
  • 05 Clean Slack Canvas reports using native Slack surfaces.

Current Architecture (Slack-First)

  • Single source of truth = Salesforce Developer Org
  • Agent Layer = Slack Agent Builder + Bolt + Native Surfaces
  • Bridge = Salesforce MCP + Slack MCP Server
  • Real-Time Search (RTS) = Core capability pulling fresh workspace context instantly
  • Clinical Reasoning = Claude (used selectively)
This architecture aligns with Slack's official guidance on Agent Builder, Slack MCP Server, and native surfaces. Real-Time Search (RTS) ensures the agent is always working with the latest data from both Slack and Salesforce.
